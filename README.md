> **Коммерческий мини-продукт (Turnkey B2B Extension)**: 1-Click парсер профилей и контактов для LinkedIn, GitHub, Twitter/X и веб-сайтов. Находит имя, должность, компанию, геолокацию, корпоративный email и телефон, сохраняет во внутреннюю базу, экспортирует в Excel (CSV)/JSON и автоматически отправляет лидов по Webhook в CRM (HubSpot, Notion, Zapier, Make.com, n8n).

## 🚀 Быстрый старт за 3 минуты

Установка в любой Chromium-браузер (Google Chrome, Brave, Microsoft Edge, Opera, Яндекс.Браузер):

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/Max/lead-harvest-pro.git
   cd lead-harvest-pro
   ```
2. **Откройте страницу расширений в браузере:**
   - Введите в адресную строку `chrome://extensions/`
   - Включите переключатель **«Режим разработчика»** (Developer mode) в правом верхнем углу.
3. **Загрузите расширение:**
   - Нажмите **«Загрузить распакованное расширение»** (Load unpacked).
   - Выберите папку `lead-harvest-pro`.
4. **Готово!** Иконка молнии ⚡ появится на панели инструментов. Зайдите на любой профиль в LinkedIn или GitHub и протестируйте захват контакта.

## ⚡ Ключевые возможности

- **Chrome Extension Manifest V3:** полное соответствие последним требованиям Google Web Store (безопасный Service Worker, zero CSP violations).
- **Zero Dependencies:** чистый легковесный JavaScript без тяжелых фреймворков (быстрая загрузка < 100 мс).
- **Regex Contact Detector:** умный поиск скрытых email и телефонных номеров в описании/bio и теле страницы.
- **Интерактивный UI Popup:**
  - Вкладка **Capture**: авто-определение текущего профиля и форма предпросмотра с возможностью ручной правки.
  - Вкладка **Saved Leads**: поиск в реальном времени, удаление, быстрое копирование в буфер обмена.
  - Вкладка **Settings**: ввод и валидация Webhook URL с тестовым пингом.
- **Экспорт данных:**
  - **CSV (Excel Ready):** формат со специальным UTF-8-BOM маркёром (кириллица корректно открывается в Excel без «кракозябр»).
  - **JSON:** структурированный массив для разработчиков и автоматизаторов.
